# 快速开始

本页面给第一次使用 Robot Dashboard 的操作者准备。目标不是立刻让机器人运动，而是在知道每个控制的作用和边界后，安全完成第一个任务。

## 1. 开始前

请确认：

- 机械臂活动范围内无人、无松散线缆和障碍物；必要时让机械臂处于观察位。
- 底盘周围有足够空间；首次测试请抬起驱动轮或选择不会使底盘移动的功能。
- 电池电压正常，网络已连接，浏览器能打开 `http://<机器人IP>:8000`。
- 初次尝试时保持驱动锁定。只有确认环境安全、知道将发生什么时才解锁。

## 2. 认识工作台

| 页面 | 适合做什么 | 不能替代什么 |
| --- | --- | --- |
| JETROVER 工具台态势中心 | 总览通信、安全、电源、相机和数字孪生 | 不能绕过底盘/机械臂安全锁 |
| 视觉引导抓取 | 观察画面、实时识别、检查坐标、确认抓取 | 识别到目标不代表一定可达 |
| 动作组编辑器 | 预览或执行已保存的关节动作组 | 不应用于未清场的真实环境 |
| 自主导航 | 发起探索或返航，查看导航状态 | 不会绕过 Nav2 与速度安全闸门 |
| ROS 学习 | 认识节点、服务、话题和日志 | 学习发消息仅开放安全演练话题 |
| 运维面板 | 观察服务、事件日志和资源，做受限恢复 | 不应把“重启”当作未知故障的第一反应 |

## 3. 第一次查看状态

进入 **JETROVER 工具台态势中心**，依次确认：

1. 通信链路为在线，且剩余电量没有告警。
2. 相机画面有帧率；画面标签会显示当前使用 WebRTC 或 MJPEG。
3. 安全状态仍是“驱动已锁定”。
4. 数字孪生的关节数完整。它只用于观察真实反馈，不是额外的控制通道。

如果相机黑屏、服务离线或 CPU/内存异常，请先进入[运维手册](OPERATIONS_RUNBOOK.md)的“故障决策树”。

## 4. 第一次视觉校验（不抓取）

1. 打开 **视觉引导抓取**，让物体落在画面中央、桌面边缘以外，避免强反光和过曝。
2. 点击“实时识别”，等待检测框稳定。
3. 点击检测框，选择 **只算不抓**，确认坐标、深度输入和可达性判断。
4. 只有在目标可达、场地清空、你可以随时停止的情况下，才进入抓取确认。

“IK 无解”或“当前不可达”是保护结果，不是网页故障。请调整物体位置、机械臂姿态或相机条件后重新扫描；不要通过修改坐标强行执行。

## 5. 第一次动作组预览

动作组是已保存的关节序列。打开 **动作组编辑器**：

- 卡片矩阵用于快速预览；点击卡片不会自动改变安全策略。
- 单个“执行”按键会运行对应动作组；执行中的卡片显示橙色。
- “全部执行一次”会按当前列表顺序运行，适合空场演示，不应在有人或障碍物附近使用。

同一组卡片也可在态势中心的图层中展开，便于一边执行一边观察数字孪生。

## 6. 第一次自主移动

自主探索依赖已有 Nav2、雷达和定位链路。先阅读[自主探索](AUTONOMOUS_EXPLORATION.md)，再确认：雷达已接入、地图/TF 正常、通道宽度足够、底盘周围安全。所有手动速度和导航速度都会经过安全闸门；锁定时不应有车轮动作。

暂时不需要导航时，可以在 **运维面板** 切换“自主导航待机”，释放 Nav2/SLAM 资源；视觉抓取、相机和安全闸门仍保持可用。
