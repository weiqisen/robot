# 供电与 USB 反向供电

Jetson 单独供电时，连接辅助控制板的 USB 线仍会提供 5V VBUS。辅助板的 STM、USB 转串口或指示灯可能因此亮起，甚至部分逻辑控制仍能响应；这不代表底盘电池、电机电源和雷达已经正常上电。

系统“关机”只停止 Jetson 操作系统和 SoC，不等于切断 DC 输入或 USB 5V 电源轨。需要彻底断电时：

1. 停止所有运动命令并等待轮子静止。
2. 关闭/断开底盘电池和大功率负载。
3. 断开 Jetson 外部电源。
4. 如辅助板仍亮，断开 Jetson 与辅助板之间携带 VBUS 的 USB 线。

不要在两套供电都开启时随意插拔电机、舵机或电源线，也不要把“指示灯亮”作为电源域正常的判断。USB 反向供电可能让 USB 口承担设计外电流；若要长期让 Jetson 与底盘分开供电，应使用厂商确认的隔离/去 VBUS 方案，而不是自行剪线。

软件上的判断应以实时数据为准：

- `/ros_robot_controller/battery`：底盘控制器和电池链路。
- `/scan` 与 `/dev/lidar`：雷达供电和数据链路。
- `/nav_safety/state`：运动安全闸门、雷达心跳和当前授权控制源。

Jetson 单独供电且 `/dev/lidar` 不存在时，`exploration-nav.service` 只等待硬件，不加载高开销的 SLAM/Nav2。
