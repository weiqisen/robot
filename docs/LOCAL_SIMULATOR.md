# Mac 本地模拟器

小车关机或充电时，使用本模拟器联调网页、探索任务恢复和抓取动作恢复。它是
`rosbridge` 的最小兼容实现，不含物理引擎，也**绝不会**发送控制命令到实体机器人。

## 启动

终端一启动模拟器，另一个终端启动网页：

```bash
cd /Users/weiqisen/Desktop/robot
python3 tools/sim_robot.py

npm --prefix studio-vue run dev -- --host 127.0.0.1 --port 5274
```

打开 <http://localhost:5274/?sim=1#explore> 或
<http://localhost:5274/?sim=1#snack>。`?sim=1` 仅把网页的 ROS 地址切到
`127.0.0.1:19090`；正常本地预览仍默认连接真车 `192.168.3.63`。选择独立端口是为了
不干扰本机可能已有的 ROS/rosbridge。需要换端口时同时使用 `--port 19091` 与
`?sim=1&simPort=19091`。

## 能模拟什么

- `/map`、`/scan`、`/odom`、电池、关节、Jetson GPU 遥测与服务状态；
- 探索启动、暂停、继续、返航、底盘安全闸门；
- 抓取动作的中断日志与“安全恢复”；
- 探索页的“本地仿真控制”：雷达离线、低电压、服务重启和恢复。

“模拟服务重启”会把正在探索的任务放入人工确认恢复状态；抓取中的动作会转为
`RECOVERY`。这是验证断点恢复 UI 的推荐方式。

## 不模拟什么

它不模拟碰撞动力学、轮胎打滑、真实 Nav2 规划、相机深度误差或机械臂运动学。
这些仍必须在真机空跑后验证。后续可把真机 rosbag/相机录像接入回放，作为真实
故障的回归样本。
